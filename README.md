# Fixed-wing UAV GNC Simulation

## Overview 

This project develops a Python-based nonlinear six-degree-of-freedom
simulation of a fixed-wing UAV capable of closed-loop flight control
and autonomous waypoint navigation.

## Objectives

- Develop a nonlinear 6-DOF aircraft model
- Implement aerodynamic and propulsion models
- Determine trimmed steady-level flight conditions
- Develop closed-loop altitude, airspeed, and heading control
- Implement waypoint guidance
- Verify system performance against defined requirements

## Aircraft

Aerosondre Mk 1 UAV

## Tools
